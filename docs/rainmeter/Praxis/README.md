# PRAXIS Rainmeter Skin Draft

This draft binds to the read-only PRAXIS snapshot at:

`memory/runtime/rainmeter/praxis-snapshot.json`

Set `SnapshotPath` in `Praxis.ini` to the absolute snapshot path on the operator machine. The skin is
display-only. It has no command endpoint and cannot write SQLite, markdown memory, provider events,
or settings.
